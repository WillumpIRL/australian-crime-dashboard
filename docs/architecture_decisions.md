# Architecture Decisions

## ADR-001: Initial Dataset Selection

Date:
2026-07-28

## Decision

The first release of the Australian Crime Analytics Dashboard will use the Australian Bureau of Statistics Recorded Crime - Offenders dataset.

## Reason

The dataset provides:

- Official Australian crime statistics
- Longitudinal data from multiple years
- Offence category analysis
- Demographic analysis opportunities

## Impact

The first dashboard release will analyse recorded offenders rather than total crime incidents.

Future versions may incorporate police incident datasets to provide broader crime occurrence analysis.

## Limitations

Recorded offenders do not represent total criminal incidents.

Results should be interpreted as offender statistics, not total crime rates.
