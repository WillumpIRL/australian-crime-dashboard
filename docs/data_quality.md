# Data Quality Notes

## Missing Offender Rates

The ABS offender dataset contains missing offender rate values for financial years:

- 2016–17
- 2017–18
- 2018–19
- 2019–20
- 2020–21

The missing values affect all major offence categories.

Offender counts remain available for these years.

The dashboard should use offender counts for trend analysis during this period and display rate-based visualisations only where ABS rate data is available.
