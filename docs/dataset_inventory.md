# Dataset Inventory

## Dataset 1

Name:
Australian Crime Statistics

Source:
Australian Government Open Data

Purpose:
Provide national crime trend analysis.

Expected Usage:
- Crime trends over time
- State comparisons
- Offence category analysis

Storage:

Raw:
data/raw/

Processed:
data/processed/

Limitations:

- Represents recorded offences
- Does not represent all criminal activity
- Reporting practices may vary
