# Data Sources

## Crime Dataset

### Purpose

Provides Australian crime statistics for dashboard analysis.

### Source

To be selected.

### Expected Fields

- State
- Year
- Offence category
- Recorded offences

### Processing

Raw data will be stored in:

data/raw/

Processed data will be stored in:

data/processed/

### Limitations

Crime statistics represent reported offences and may not represent all actual criminal activity.
